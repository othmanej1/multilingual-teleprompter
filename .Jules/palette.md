## 2025-02-28 - ARIA Labels for Symbol Buttons in Sidebar Panels
**Learning:** Icon-only buttons and inline controls in sidebar panels (like Script Library) require explicit `aria-label` attributes for screen reader accessibility when visually represented only by unicode symbols or icons (e.g., ✎, ⧉, ⤐, ✕, ✦).
**Action:** Always verify that every symbol/icon button and unlabelled form input in panel interfaces includes an informative `aria-label` attribute.
